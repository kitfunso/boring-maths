3. What PR #37 changes

  • Share images from the registry. The old generator kept a hand list of 77 calculators, unchanged since 2026-01-22, and every card drew a "NO GLYPH" box where the emoji should be. Now src/pages/og/[slug].webp.ts renders one card per registry entry at build time (182 images including the default). A new postbuild gate, check-og-images.mjs, fails the build when any page's og:image is missing; against the old build it reports 110 of 230 pages.
  • IndexNow. A key file at the site root and npm run seo:indexnow, which posts the live sitemap to api.indexnow.org and refuses to run before the key file is deployed.
  • Build fix. Tailwind no longer scans docs/; a local report there had broken the build with "Invalid code point 1120278".

Checks: build 240 pages, six postbuild gates OK; suite 1289/1289; lint 0 errors; sitemap unchanged at 229 URLs.
